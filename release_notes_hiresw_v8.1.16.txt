#####################
Update overview 
#####################

* Trims down the HiresW system to only run for the Guam domain
* This also removes NAM, RAP, and SREF references from the system

#####################
Obtaining the package
#####################

Clone it with this command (but change hiresw.v8.1.16 to whatever you want 
to call it in the directory that it is cloned into):


git clone -b feature/guamonly \
https://github.com/MatthewPyle-NOAA/hiresw.git hiresw.v8.1.16


#####################
Building the package
#####################


Go to sorc/ of the cloned package

./build_all.sh (compiles code)

./install_all.sh (copies to exec/ of the package)

The build_all.sh step also copies in the fix files to the package.

#############################
Resource changes:
#############################

Guam resources are unchanged.  Overall HiresW resource usage drops 
significantly, as is limited to 00Z and 12Z cycles now, and the forecast jobs 
for Guam only use 1 node (ARW) and 2 nodes (FV3).

WMO products are about 186 MB/day for Guam-only system (current HiresW is 
about 6 GB/day)

COM storage is about 58 GB/day for this Guam-only system (current HiresW is 
about 1.2 TB/day)

Volume to HPSS should see a similar level of drop, but was not directly 
investigated.  An updated runhistory/parm/models/hiresw type file is on 
cactus/dogwood as 
/lfs/h2/emc/lam/noscrub/Matthew.Pyle/hiresw.v8.1.16/hpss/hiresw
